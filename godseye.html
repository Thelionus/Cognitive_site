What this is

A photorealistic 3D globe with live aircraft, ships, satellites, earthquakes, and public cameras — built by Bilawal Sidhu as gods-eye-view (MIT licensed). It's not part of the Cognitive Group platform — this page just points to it.

It runs as its own local app, not something we host here: its live-data proxying is built into its dev server, so it needs to actually be running on your machine (or wherever you choose to deploy it) for the button above to go anywhere.

Run it locally

Requires Node.js 24.x or 26.x. First time only:

git clone https://github.com/bilawalsidhu/gods-eye-view.git
cd gods-eye-view
npm ci

Then, every time you want to use it:

npm run dev

It opens at http://localhost:4173 and runs keyless by default — live flights, ships, satellites, earthquakes and cameras all work without an account. Add a Cesium ion token or Google Maps key later, from inside the app's own "POWER UP" panel, for photorealistic 3D tiles.
